# fixli-status

Отчёт о состоянии IT-работ для партнёров Fixli — онлайн-версия документа
`.business/отчёты/` из рабочего репозитория проекта.

Страница лежит по неугадываемому адресу, корень отдаёт заглушку. Из поиска
закрыта мета-тегом `noindex`; в `robots.txt` запрета нет намеренно — иначе
пропало бы превью ссылки в WhatsApp.

Файлы собирает `собрать.py` из проекта, вручную здесь ничего не правится.
