# Брендбук и брендкит Fixli

Открывается по ссылке: https://docs.fixlihome.co.il/brand/

Это подпапка `brand/` в репозитории документов Fixli — того, что отправляется
ссылкой. Рядом живут отчёт партнёрам и проход по связке, у каждого свой сегмент.

**Здесь ничего не правится руками.** Репозиторий собирается скриптом
`scripts/собрать-брендбук.py` из рабочего репозитория проекта — правка делается
там, а сюда приезжает целиком.

Что внутри:

| Папка | Что |
|---|---|
| `book/` | Брендбук: одиннадцать разделов и печатаемый съёмочный лист |
| `kit/ads/` | Рекламные креативы: шаблоны, реестр обещаний и 24 готовых PNG |
| `kit/transport/` | Транспорт и спецодежда: схемы раскладки, два ТЗ подрядчикам, замеры оклейки |
| `kit/print/` | Печать и документы: восемь документов на двух языках, 16 PDF, ТЗ типографии |
| `kit/digital/` | Цифра: иконка панели, аватары двух Telegram-ботов, подпись в почте, витрина знаков |
| `знак/` | Знак и марка в векторе, четыре SVG с описью |
| `fonts/` | Rubik, четыре подмножества, лицензия OFL рядом |
| `system/` | Дизайн-система в коде: 29 компонентов в браузере |
| `tokens.css` | Все значения бренда одним файлом |
| `контрасты.md` | Каждая допустимая пара «фон × текст» с числом |

Документ закрыт от поиска мета-тегом `noindex` в каждой странице. Запрета в
`robots.txt` нет намеренно — он убил бы превью ссылки в мессенджере.
